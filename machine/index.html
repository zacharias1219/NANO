Backprop Machine

A see-through picture of Nano's tape. Every number on this page is read from report/results.json (E2, step 0); if a number is not in that file, it does not appear here.

Cell

Pipe width at each station is proportional to log10 of that layer's real gradient norm ‖∂L/∂W‖ at step 0 (geometric mean over 5 seeds). A pipe that starves toward layer 1 is a vanishing gradient.

Tape reel

    Each forward op is recorded on the tape; backward replays it in reverse.

    im2col station (CNN)

    A 3×3 kernel over a 5×5 input. Forward: every receptive field is copied into one column, so the convolution becomes a single matmul. Backward: col2im adds each column's gradient back onto the pixels it came from; overlapping windows accumulate, which is why col2im is the adjoint of im2col (D8.2).

    Each of the 9 output pixels has a 9-value receptive field.
